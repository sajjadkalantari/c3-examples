# Input Directory

Place your input files here for use in the text-to-image and video generation workflows.

## Audio Files for Video Generation

Place audio files (e.g., welcome.flac) in this directory to use them for video generation with talking portrait animations.

Supported audio formats:
- FLAC (.flac)
- WAV (.wav)
- MP3 (.mp3)

The audio file should be relatively short (recommended under 30 seconds) for best results with the SONIC model.
